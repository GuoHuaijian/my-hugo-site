## 秒杀请求数据流

```
用户点击 "立即抢购"
    │
    ▼
1. 网关层
   Request: GET /api/v1/seckill/{id}
   Headers: X-Trace-Id, Authorization, X-User-Id
    │
    ▼
2. 认证服务
   - 验证 JWT Token
   - 获取用户信息
   - 检查用户权限
    │
    ▼
3. 秒杀服务
   - Sentinel 限流检查
   - 校验链（活动/用户/重复/限购）
   - Redis 预减库存（Lua）
   - Redisson 分布式锁
   - 发送 RocketMQ 消息
   - 返回 "排队中"
    │
    ▼
4. 消息队列
   Topic: seckill-topic
   Message: SeckillOrderMessage
    │
    ▼
5. 订单服务（MQ 消费）
   - 幂等校验
   - Seata @GlobalTransactional
   - 创建订单（ShardingSphere 分片写入）
   - Dubbo 调用库存服务扣减库存
    │
    ▼
6. 库存服务
   - 乐观锁更新库存
   - 记录库存流水
    │
    ▼
7. 结果处理
   - 保存结果到 Redis（供前端轮询）
   - 发送延迟消息（30分钟超时检查）
   - 通知用户
```

## 支付数据流

```
用户选择支付 → 跳转支付页面 → 支付成功 → 回调通知
                                                 
1. 生成支付请求（金额、订单号、回调地址）
2. 调用支付网关（微信/支付宝）
3. 用户扫码支付
4. 接收异步回调 → 验证签名 → 更新支付状态 → 更新订单状态
5. 发送通知（短信、站内信、邮件）
```

## 库存数据流

```
秒杀预减（Redis Lua） → 实际扣减（MySQL 乐观锁） → 库存同步 → 库存预警

- 预减：Redis DECR 原子操作，设置售罄标记
- 扣减：UPDATE ... WHERE version = #{v} 乐观锁更新
- 同步：定时任务检查 Redis 和 MySQL 一致性
- 预警：库存 < 10 触发低库存预警
```
