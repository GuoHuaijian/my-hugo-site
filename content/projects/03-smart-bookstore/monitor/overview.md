## 核心组件

| 层面 | 组件 | 用途 |
|------|------|------|
| 采集层 | Micrometer | 统一指标 API，Spring Boot 集成 |
| 采集层 | SkyWalking Agent | 分布式链路追踪，自动探针 |
| 采集层 | Prometheus Exporter | 系统指标采集 |
| 采集层 | Filebeat | 日志收集 |
| 存储层 | InfluxDB | 时序数据库，存储指标数据 |
| 存储层 | MySQL | 关系数据库，存储配置和告警数据 |
| 存储层 | Elasticsearch | 搜索引擎，存储日志数据 |
| 处理层 | AlertManager | 告警管理和路由 |
| 可视化 | Grafana | 主力可视化工具 |

## 监控范围

### 系统监控
- **CPU**：使用率、负载、IO 等待
- **内存**：使用率、可用、已用、总量
- **磁盘**：使用率、空闲空间、Inode
- **网络**：出入字节数、包数

### JVM 监控
- **堆内存**：使用率、已用、最大
- **GC**：Young/Old GC 次数和耗时
- **线程**：总数、守护线程、峰值

### 应用监控
- **HTTP**：请求数、响应时间、状态码分布
- **数据源**：活跃连接数、最大连接数
- **业务**：秒杀请求量、库存水平、订单处理

### 中间件监控
- **Redis**：命令数、连接数、内存使用、缓存命中率
- **RocketMQ**：生产/消费速率、队列堆积、消息延迟
