## Grafana 配置

### Prometheus 数据源

```yaml
apiVersion: 1
datasources:
  - name: Prometheus
    type: prometheus
    access: proxy
    url: http://prometheus:9090
    isDefault: true
    editable: true
```

### 导入仪表盘

```bash
# 通过 API 导入
curl -X POST http://admin:admin@localhost:3000/api/dashboards/db \
  -H "Content-Type: application/json" \
  -d @dashboard.json
```

### Prometheus 抓取配置

```yaml
scrape_configs:
  - job_name: 'bookstore-services'
    metrics_path: '/actuator/prometheus'
    static_configs:
      - targets:
        - 'gateway:8000'
        - 'seckill:8050'
        - 'order:8040'
        - 'inventory:8030'
        - 'user:8010'
```

## 关键面板指标

| 面板 | 指标 | 刷新频率 |
|------|------|---------|
| 系统概览 | CPU、内存、磁盘、网络 | 10s |
| 应用性能 | QPS、响应时间、错误率 | 5s |
| 业务监控 | 秒杀量、订单量、支付量 | 5s |
| JVM 监控 | 堆内存、GC、线程 | 15s |
| 中间件 | Redis、MQ、DB | 15s |
