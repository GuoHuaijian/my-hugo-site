## 3. 高可用与容错设计

### 高可用
- **服务高可用**：多实例部署，Nacos 负载均衡
- **缓存高可用**：Redis Cluster 或 Sentinel 模式，多级缓存
- **消息队列高可用**：RocketMQ 主从架构，同步刷盘
- **数据库高可用**：MySQL 主从复制，ShardingSphere 读写分离

### 容错
- **限流**：网关层 API 级别 + 服务层资源级别 + 热点参数级别
- **熔断**：调用失败率超过阈值触发熔断，快速失败
- **降级**：限流触发时返回友好提示
- **超时控制**：Dubbo 调用 5s，数据库操作 30s，分布式事务 30s

### 安全
- JWT Token 认证，网关统一鉴权
- 分布式锁防重复提交
- 限流 + 黑名单防刷
- 敏感数据加密存储，日志脱敏

## 4. 自动装配与配置

```yaml
spring:
  cloud:
    nacos:
      discovery:
        server-addr: localhost:8848
      config:
        server-addr: localhost:8848

dubbo:
  protocol:
    name: dubbo
    port: -1
  registry:
    address: nacos://localhost:8848

sentinel:
  datasource:
    flow:
      nacos:
        server-addr: localhost:8848
        data-id: ${spring.application.name}-flow-rules
        rule-type: flow
```
