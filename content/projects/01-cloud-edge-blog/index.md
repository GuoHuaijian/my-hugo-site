# 云边小卖部

> 像走进云边镇的小卖部——外面是山风和晚霞，里面是整齐的货架和温暖的灯光。

一个基于 **Vite + Vue 3** 的静态 Markdown 个人博客系统。所有内容基于 Markdown 文件管理，无需后端数据库，零成本部署到 GitHub Pages 或任意静态托管平台。

## 核心特性

- **Markdown 驱动**：所有笔记、项目文档、读书笔记均使用 Markdown 编写
- **零后端**：纯前端架构，无需数据库或服务器
- **内容索引自动生成**：运行 `npm run generate` 自动扫描内容目录生成 JSON 索引
- **PDF 阅读支持**：书籍章节支持 PDF 格式，浏览器原生渲染
- **响应式设计**：完美适配桌面、平板、手机
- **温暖设计语言**：霞鹜文楷字体、靛蓝紫强调色、柔和粒子动画
