# Agent Forge

Agent Forge 是一个轻量级 AI Agent 编排框架，旨在降低构建智能代理工作流的门槛。

## 核心理念

- **组合优于继承**：工具、记忆、推理策略都是可插拔的组件
- **渐进式复杂度**：从单 Agent 单工具到多 Agent 协作，按需升级
- **可观测优先**：每个决策步骤都可追踪、可回放、可调试

## 适用场景

- 智能客服 / 知识库问答
- 自动化报告生成
- 多步骤数据处理流水线
- 代码分析与自动修复

## 技术栈

| 层面 | 技术选型 |
|------|---------|
| 运行时 | Python 3.11+ |
| LLM 抽象 | LiteLLM（兼容 OpenAI / Claude / 本地模型） |
| 向量存储 | ChromaDB / Milvus |
| 任务队列 | Celery + Redis |
| 可观测 | OpenTelemetry |
